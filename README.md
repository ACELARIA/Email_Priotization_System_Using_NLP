# Email Priority Classification System

An NLP-based system that automatically classifies emails into four priority levels — **High Priority**, **Medium Priority**, **Low Priority**, and **Spam** — using TF-IDF feature extraction and machine learning.

---

## Features

- **Single & batch email classification** — classify one email or a list at once
- **Confidence scores** — per-class probability breakdown for every prediction
- **Two-model comparison** — trains both Multinomial Naive Bayes and Logistic Regression; selects the better one automatically
- **Synthetic dataset** — ~2 000 realistic labelled samples generated deterministically (no external data required)
- **Enron dataset support** — drop in a compatible CSV to train on real-world email data
- **Clean web UI** — fully offline single-page app (no CDN dependencies)
- **REST API** — `/predict`, `/batch_predict`, `/health` endpoints

---

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model

```bash
python model/train.py
```

This generates three files in `model/`:
- `email_model.pkl` — best trained classifier
- `tfidf_vectorizer.pkl` — fitted TF-IDF vectoriser
- `label_encoder.pkl` — label class list

### 3. Start the web server

```bash
python app/app.py
```

Open **http://localhost:5000** in your browser.

---

## How to use

### Web UI
- Paste an email subject and body into the **Single Email Classification** card and click **Classify Email**.
- Click **Run Batch Demo** to classify five pre-loaded example emails and see results sorted by priority.

### API

**Single prediction**
```http
POST /predict
Content-Type: application/json

{"subject": "URGENT: server down", "body": "Fix immediately."}
```

Response:
```json
{
  "priority": "High Priority",
  "confidence": 0.97,
  "confidence_scores": {
    "High Priority": 0.97,
    "Medium Priority": 0.02,
    "Low Priority": 0.005,
    "Spam": 0.005
  }
}
```

**Batch prediction**
```http
POST /batch_predict
Content-Type: application/json

{"emails": [{"subject": "...", "body": "..."}, ...]}
```

**Health check**
```http
GET /health
```

## Dataset

The system ships with a **synthetic dataset generator** (`data/preprocess.py`) that produces ~2 000 labelled email samples across the four classes. Each sample is built from realistic subject and body templates with randomised placeholder values (random seed = 42 for reproducibility).

To use the **Enron email dataset** instead, pass the path to a compatible CSV (columns: `subject`, `body`, `label`) to `load_dataset(enron_csv_path="...")` in `data/preprocess.py`.
